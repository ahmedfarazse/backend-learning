# Logging

This folder contains examples and practice related to logging in backend applications.

The goal is to understand how backend applications record requests, responses, warnings, errors, and other important events for debugging and monitoring.

---

## Purpose

- Understand logging
- Understand why logging is important
- Log HTTP requests
- Log response status codes
- Log response time
- Understand different log levels
- Log application errors
- Practice logging with Express.js
- Understand the difference between logging and error handling
- Avoid logging sensitive information
