# CORS

This folder contains examples and practice related to Cross Origin Resource Sharing (CORS) in backend applications.

The goal is to understand how browsers handle cross origin requests and how CORS can be configured in an Express.js backend.

---

## Purpose

- Understand CORS
- Understand the Same Origin Policy
- Understand origins
- Understand same origin and cross origin requests
- Configure CORS in Express.js
- Allow specific origins
- Understand CORS credentials
- Understand preflight requests
- Understand the difference between CORS and authentication
- Practice CORS with Express.js
