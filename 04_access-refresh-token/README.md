# Access and Refresh Tokens

This folder contains examples and practice related to access tokens and refresh tokens in backend authentication.

The goal is to understand how access and refresh tokens work together to provide secure and continuous authentication.

---

## Purpose

- Understand access tokens
- Understand refresh tokens
- Learn the difference between access and refresh tokens
- Understand token expiration
- Practice generating access and refresh tokens
- Practice refreshing expired access tokens
- Understand logout and token revocation
- Understand the authentication flow using access and refresh tokens
