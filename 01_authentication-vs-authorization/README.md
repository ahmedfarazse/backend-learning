# Authentication vs Authorization

This folder contains examples and practice related to authentication and authorization in backend applications.

The goal is to understand how authentication verifies a user's identity and how authorization controls what an authenticated user is allowed to access.

---

## Purpose

- Understand authentication
- Understand authorization
- Learn the difference between authentication and authorization
- Practice authentication middleware
- Practice authorization middleware
- Understand HTTP status codes 401 and 403
- Understand protected routes
