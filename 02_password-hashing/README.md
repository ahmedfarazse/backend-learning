# Password Hashing

This folder contains examples and practice related to password hashing in backend applications.

The goal is to understand how passwords are securely stored and verified using password hashing techniques.

---

# Purpose

- Understand password hashing
- Learn why plaintext passwords should not be stored
- Understand hashing vs encryption
- Understand salts
- Learn about bcrypt
- Practice hashing passwords
- Practice verifying passwords
- Understand password verification during login
