# Testing

This folder contains examples and practice related to testing backend applications.

The goal is to understand the basics of automated testing, unit testing, API testing, assertions, and testing different success and error scenarios in an Express.js application.

---

## Purpose

- Understand software testing
- Understand automated testing
- Understand unit testing
- Understand API testing
- Learn how assertions work
- Test successful API requests
- Test error responses
- Test HTTP status codes
- Test response data
- Practice testing Express.js APIs
- Use Node.js built in test runner
