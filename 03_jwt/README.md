# JWT

This folder contains examples and practice related to JSON Web Tokens (JWT) in backend authentication.

The goal is to understand how JWTs are created, verified, and used to authenticate users and protect backend routes.

---

# Purpose
- Understand JSON Web Tokens
- Learn the structure of a JWT
- Understand Header, Payload, and Signature
- Generate JWTs
- Verify JWTs
- Understand JWT expiration
- Use JWTs for authentication
- Protect backend routes using JWT middleware
- Practice sending JWTs using the Authorization header
