# Role-Based Access Control (RBAC)

This folder contains examples and practice related to Role Based Access Control (RBAC) in backend applications.

The goal is to understand how different users can be given different levels of access based on their roles.

---

## Purpose

- Understand Role Based Access Control
- Understand roles and permissions
- Differentiate authentication and authorization
- Implement role based authorization
- Create authorization middleware
- Restrict routes based on user roles
- Understand 401 and 403 status codes
- Practice allowing multiple roles on a route
- Protect admin and manager routes
