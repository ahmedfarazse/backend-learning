# Cookies and Sessions

This folder contains examples and practice related to cookies and sessions in backend authentication.

The goal is to understand how cookies and sessions work together to maintain user authentication in backend applications.

---

## Purpose

- Understand cookies
- Understand sessions
- Learn the difference between cookies and sessions
- Understand session based authentication
- Practice creating sessions
- Practice protecting routes using sessions
- Understand session cookies
- Learn basic cookie security options
- Practice session logout and destruction
