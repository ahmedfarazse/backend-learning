# Rate Limiting

This folder contains examples and practice related to rate limiting in backend applications.

The goal is to understand how rate limiting controls the number of requests a client can make within a specific time period.

---

## Purpose

- Understand rate limiting
- Understand why rate limiting is important
- Learn about request limits
- Understand time windows
- Use rate limiting with Express.js
- Protect API routes from excessive requests
- Understand HTTP 429 status code
- Create route specific rate limiters
- Apply stricter limits to sensitive endpoints
