# Error Handling

This folder contains examples and practice related to error handling in Express.js backend applications.

The goal is to understand how errors are created, passed through middleware, and handled using centralized error handling middleware.

---

## Purpose

- Understand error handling in Express.js
- Understand the `next()` function
- Pass errors using `next(error)`
- Understand error handling middleware
- Create custom errors
- Use HTTP status codes with errors
- Handle 404 errors
- Handle unexpected server errors
- Keep error responses consistent
- Practice centralized error handling
